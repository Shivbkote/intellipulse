# IntelliPulse Solutions LLP — Homepage

## Files
- `index.html` — semantic page structure and sample content
- `styles.css` — responsive luxury corporate design, glass navigation and animations
- `script.js` — mobile navigation, sticky header, profile dropdown, search, event filters, scroll reveals
- `assets/intellipulse-logo.jpg` — logo cropped from the screenshot you supplied

## Run locally
1. Extract the ZIP.
2. Keep `index.html`, `styles.css`, `script.js` and the `assets` folder together.
3. Open `index.html` in a modern browser. For best results, use a local server such as VS Code Live Server.
4. Replace the sample event titles/dates, email address, profile links and policy links with your real content.

## Customisation
- Colours are defined at the top of `styles.css` under `:root`.
- The hero and event imagery use Unsplash image URLs. Replace those URLs with your own optimised local images if preferred.
- The cropped logo is taken from the screenshot and may be lower resolution than the original logo file. Replace `assets/intellipulse-logo.jpg` with your original high-resolution logo for the best result.
- The search and notification interactions are front-end demos. Connect them to your actual backend/authentication system for production.
- This is a static front-end homepage; it does not include a booking database, authentication, or payment processing.
